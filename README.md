# ABSKA — 214 | التحوّل الشامل

> **نظام شخصي متكامل لإحداث تحوّل شامل في الحياة خلال 214 يومًا**  
> تطبيق ويب تقدمي حقيقي (PWA) يعمل **100% دون اتصال بالإنترنت** مع تخزين محلي دائم وآمن عبر **IndexedDB**، وتصميم سينمائي باللونين الأسود الفاخر والماروني الداكن.

---

## 🌟 نظرة عامة وفلسفة المشروع

**ABSKA 214** ليس مجرد تطبيق لإنقاص الوزن أو قائمة مهام عادية؛ بل هو نظام هندسي لتطوير الذات يجمع بين:
1. **التقدم أهم من الكمال**، والاستمرارية اليومية أهم من الحماس المؤقت.
2. **التعامل الإيجابي الهادئ**: لا وجود لخطاب التوبيخ أو التأنيب عند تفويت يوم أو انخفاض الطاقة.
3. **التكيّف الذكي بالقواعد المحلية**: اقتراحات واقعية لتخفيف المهام أو تقسيمها بناءً على بياناتك الفعلية دون الحاجة لخوادم خارجية.
4. **الخصوصية المطلقة**: جميع مذكراتك، صورك، وقياساتك تُحفظ داخل جهازك فقط عبر متصفحك.

## 🚀 الوظائف والميزات المنفذة بالكامل (36 محورًا)

1. **شاشة إعداد أولي ذكية (Onboarding)**: جمع أهداف المستخدم والوقت المتاح والقيود، مع زر رسمي «ابدأ رحلتي» لتثبيت تاريخ البداية.
2. **تتبع دقيق لـ 214 يومًا**: حساب اليوم الفعلي والوقت المتبقي ونسبة الإنجاز اعتمادًا على تاريخ البداية الثابت الذي لا يتغير بإعادة التحميل.
3. **لوحة قيادة سينمائية (Dashboard)**: تحية شخصية، اليوم الحالي، الرتبة ونقاط الخبرة XP، سلسلة الالتزام، مستوى الطاقة، ومؤشر التقدم الشامل.
4. **نظام المهام المتدرج الذكي**: تصنيف المهام حسب الصعوبة والوقت والمحور، مع إمكانية الإنجاز، التأجيل الهادئ، والحذف.
5. **شجرة تطوير الشخصية (7 مسارات مستقلة)**:
   - الجسم واللياقة
   - الانضباط والاستمرارية
   - المعرفة والقراءة
   - المهارات والمشاريع
   - تنظيم الوقت والحياة
   - اكتشاف الذات والسلوك
   - العادات الشخصية والروحية
6. **مقياس التغيير الشامل (مخطط الرادار SVG)**: مؤشر متعدد الأبعاد بأوزان معلنة، لا يهيمن عليه الوزن البدني إطلاقًا.
7. **نقاط الخبرة والألقاب وبنك المكافآت**:
   - 8 رتب عربية مميزة (من «المبتدئ الواعي» حتى «رائد التحوّل الشامل»).
   - حماية صارمة تمنع احتساب النقاط مرتين عند النقر المتكرر أو تحديث الصفحة.
   - بنك مكافآت شخصية آمنة (مشاهدة فيلم، اقتناء كتاب، نزهة).
8. **خريطة رحلة الـ 214 يومًا**: خريطة بصرية تفاعلية مقسمة إلى 8 مراحل لكل منها أهدافها وفلسفتها مع متفقد للأيام.
9. **تحديات الـ 30 يومًا ومولّد التحديات الشخصي**: توليد تحديات محلية مخصصة حسب المحور والصعوبة وقبولها أو تغييرها.
10. **وضع اليوم الصعب (Tough Day Mode)**: خطة الحد الأدنى الواقعي (قراءة صفحة، 3 دقائق تمدد، تدوين سطر) وتأجيل المهام الثقيلة دون تأنيب.
11. **نظام الإنقاذ والعودة إلى المسار (Relapse Rescue)**: دعم هادئ لتحديد أسباب التعثر، واختيار خطوة مصغرة لاستعادة الزخم دون تصفير النقاط أو الأيام.
12. **عقد المرحلة الشخصي (Stage Contract)**: وثيقة عهد في بداية كل مرحلة تحدد التزاماتك ومكافأتك مع توقيع رمزي وأرشفة للإصدارات.
13. **مكتبة القراءة والتطبيق العملي**: متابعة صفحات الكتب، تدوين الاقتباسات، وتحويل التطبيق العملي المستخلص إلى مهمة مباشرة في خطتك.
14. **مشاريع المهارات العملية**: مشروع لكل مرحلة مقسم إلى خطوات فرعية ونسبة إنجاز ومصادر.
15. **دفتر اكتشاف الذات**: أسئلة تأملية عميقة، متابعة المزاج ومستوى الطاقة، وخاصية تصدير المذكرات كملف نصي.
16. **تنظيم وإدارة الوقت**: مخطط الفترات اليومية، كاشف تعارض المواعيد، ومقارنة الوقت المخطط بالوقت الفعلي.
17. **قائمة تجارب أريد خوضها**: قائمة طموحات وتجارب جديدة مع مستوى الحماس والتوثيق بعد التجربة.
18. **المتابعة البدنية والنشاط (اختياري)**: متابعة الوزن والنشاط الحركي برفق وأمان، بعيدًا عن التجويع أو التمارين القاسية.
19. **أرشيف التغيير والصور المرحلية**:
   - توثيق مراجعات نهاية كل مرحلة (كل 30 يومًا).
   - حفظ الصور محليًا بتقنية ضغط ذكية عبر Canvas داخل IndexedDB، ومقارنة بصرية بين البداية والحالي.
20. **رسالة اليوم 214 (كبسولة الزمن)**: كتابة رسالة في اليوم الأول، وختمها حتى اليوم الـ 214 لتكشف عن عمق التغير.
21. **خطة ما بعد اليوم 214**: خطة استدامة لـ 30 يومًا بعد انتهاء الرحلة لتحويل العادات إلى هوية دائمة.
22. **النسخ الاحتياطي الكامل (JSON Backup & Restore)**: تصدير واستيراد آمن مع معاينة تفصيلية وتحقق من صحة الملف قبل التطبيق.
23. **تطبيق ويب تقدمي حقيقي (PWA)**:
   - ملف `manifest.webmanifest` متكامل.
   - `service-worker.js` مخصص للتخزين المؤقت والعمل دون اتصال.
   - أيقونات أصلية بمقاسات 192 و512 وMaskable وApple Touch Icon.
   - زر تثبيت ذكي داخل التطبيق وإرشادات تثبيت لمستخدمي iOS Safari.
24. **محاكي الأيام للاختبار**: الانتقال بين الأيام (اليوم 1، 30، 31، 210، 214) لاختبار سلوك النظام دون المساس بساعة الجهاز.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Database**: IndexedDB (مكتبة مخصصة أصلية بدون تبعيات خارجية ثقيلة مع دعم التراجع التلقائي لـ LocalStorage)
- **Offline / PWA**: Native Service Worker + Cache Storage API + Web App Manifest
- **Icons**: Lucide React
- **Icons Generation**: Script مدمج يولد صور PNG أصلية عبر zlib.

## 💻 طريقة التشغيل محليًا

### المتطلبات
- Node.js إصدار 18 فما فوق
- npm أو pnpm أو yarn

### خطوات التشغيل
1. استنساخ المشروع:
   ```bash
   git clone https://github.com/your-username/abska-214.git
   cd abska-214
   ```

2. تثبيت الحزم:
   ```bash
   npm install
   ```

3. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. بناء نسخة الإنتاج:
   ```bash
   npm run build
   ```

## 📱 متطلبات التثبيت كـ PWA

- يتطلب تثبيت PWA وجود اتصال آمن **HTTPS** في بيئات الإنتاج (أو `localhost` في التطوير).
- **أندرويد / كروم**: اضغط على زر **«تثبيت PWA»** في الشريط العلوي أو من قائمة المتصفح «تثبيت التطبيق».
- **آيفون / سفاري**: اضغط زر المشاركة (Share) ثم اختر **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.

## 🧪 خطة الاختبار والتحقق

| رقم | الوظيفة | الإجراء المتبع للتحقق |
|---|---|---|
| 1 | **الإعداد الأولي وتاريخ البداية** | إكمال شاشة الإعداد، الضغط على «ابدأ رحلتي»، التأكد من ثبات اليوم الأول بعد إعادة التحميل. |
| 2 | **تتبع الأيام والمراحل** | استخدام محاكي الأيام في صفحة الإعدادات للتبديل بين الأيام 1، 30، 31، 210، و214 والتأكد من تغير المرحلة تلقائيًا. |
| 3 | **المهام واحتساب النقاط** | إضافة مهمة، إكمالها، والتأكد من إضافة نقاط الخبرة XP وعدم تكرارها عند تكرار النقر. |
| 4 | **وضع اليوم الصعب** | تفعيله من الشريط العلوي، التحقق من ظهور المهام المصغرة وتأجيل المهام الثقيلة. |
| 5 | **العودة إلى المسار** | اختيار أسباب الانقطاع، إضافة خطوة مصغرة، والتأكد من عدم تصفير الأيام أو نقاط XP. |
| 6 | **الصور والضغط المحلي** | رفع صورة من الجهاز، التأكد من حفظها في IndexedDB كـ Base64 مضغوطة وبقاء المقارنة البصرية. |
| 7 | **النسخ الاحتياطي** | تصدير ملف JSON، تعديل بيانات، استعادة الملف، والتحقق من عودة البيانات بالكامل. |
| 8 | **العمل دون إنترنت** | قطع الاتصال في أدوات المطورين (Offline)، التنقل بين الصفحات، وإضافة مهام ومذكرات بنجاح. |
